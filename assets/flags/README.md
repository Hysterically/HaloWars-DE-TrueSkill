# Country flags

Small country flags shown beside a player's gamertag.

* **36 x 24, 3:2, PNG.** Every flag fills the same box — stretched, not cropped, so the four
  1:2 flags (Australia, Canada, Ireland, New Zealand) sit a little narrower than life. At the
  size they are drawn the distortion is not readable and nothing is cut off.
* Drawn at roughly two-thirds of the text line height. The art is deliberately more than
  twice that, so it downscales rather than going soft on a high-DPI display — please don't
  "optimise" these down to draw size.
* **File name is the country code, lowercased.** `sct` is Scotland: the UK home nations
  (ENG / SCT / WLS / NIR) are treated as first-class values, since they are not ISO 3166-1
  codes but people identify by them.
* Only countries a player has actually claimed are here. Countries are supplied by the
  players themselves — never guessed — and having no flag is a perfectly normal state.
